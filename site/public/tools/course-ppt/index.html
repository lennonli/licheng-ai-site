第一讲 · 先理解原理

大模型是怎么工作的

把复杂的模型想成一个“语言接力”系统：它根据上下文不断判断，下一步最可能出现什么。

处理链路：文字输入 → 切成词元 → 从海量文本中学习语言规律 → 按概率预测并逐字输出下一个词。它不是在“查答案”，而是在当前上下文中持续预测最合适的下一个词。

第二讲 · 从模型到行动

智能体是怎么工作的

智能体把模型接上技能、资料和操作权限，让“会回答”进一步变成“能完成任务”。

核心变化：模型负责思考，智能体负责把思考接到真实的资料、工具与动作。

第三讲 · 把工作台放到桌面

智能体桌面版 App 界面

一个顺手的工作台，应当让资料、指令、模型和结果在同一张桌面上形成闭环。

一个完整闭环：打开文件 → 输入指令 → 选择模型 → 查看状态 → 预览并交付。
