# AI实战31｜报告期要更新了，先让Agent生成一份补充尽调清单

IPO、再融资、北交所、新三板等项目推进过程中，经常会遇到报告期更新。

比如原来的核查截止日是：

**2026年3月31日**

现在要更新到：

**2026年6月30日**

这时候很多项目组会直接告诉企业：

**“请补充提供最近三个月的最新资料。”**

但这个要求其实太宽泛。

企业并不知道：

哪些资料一定要更新；

哪些只有发生变化才需要提供；

哪些历史资料不需要重复提供；

上一期还有哪些待核验事项需要继续补。

所以报告期更新真正的第一步，我更建议是：

**先让Agent根据上一期项目情况，生成一份新的“更新报告期补充尽调清单”。**

律师复核以后，再发给企业。

## 一、不要把上一期尽调清单原样再发一遍

第一次尽调时，我们可能要求企业提供：

设立文件；

历次增资资料；

历史股权转让；

历版公司章程；

重大合同；

知识产权；

诉讼处罚；

劳动用工；

各种资质证照。

但报告期从3月31日更新到6月30日以后，

很多历史事项实际上并没有变化。

比如：

公司十年前的设立资料；

已经完成核查的历史股权转让；

已经确认的早期增资。

没有必要每个报告期重新向企业索取一次。

所以补充尽调清单的核心不是：

**“原来要过什么，现在再要一遍。”**

而是：

**“哪些事项会随着时间变化，需要更新到新的截止日。”**

## 二、先让Agent把上一期项目完整看一遍

这份清单不能凭空生成。

最好让Agent先读取：

上一期尽调清单；

上一期法律意见书；

律师工作报告；

补充法律意见书；

尽调报告；

相关尽调底稿；

上一轮企业回复。

让Agent先理解：

**截至2026年3月31日，我们已经核查到了什么程度。**

然后再判断：

更新到2026年6月30日以后，哪些事项需要重新取得资料。

## 三、重点找那些“会随着时间变化”的资料

有些资料是历史性的。

例如：

公司设立文件。

如果没有发生新的变更，通常不需要每个报告期重新提供。

但有很多资料是动态的。

比如：

### 工商和公司治理

最新营业执照；

最新章程；

报告期内工商变更；

新增股东会、董事会决议；

董事、监事、高级管理人员变化。

### 股权情况

报告期内新增增资；

股权转让；

质押；

冻结；

代持变化；

员工持股平台变化。

### 资质许可

新增资质；

续期资质；

即将到期或者已经到期的许可证；

报告期内被撤销、暂停或者变更的许可。

### 主要资产

新取得或者处置的土地、房产；

新增租赁物业；

新取得知识产权；

知识产权转让、许可、质押；

到期或者失效的知识产权。

### 重大合同

报告期内新签的重大合同；

原重大合同的变更；

解除；

续签；

到期；

履行异常。

### 诉讼、仲裁和行政处罚

报告期内新增案件；

原有案件最新进展；

新增行政处罚；

监管措施；

调查事项。

### 劳动用工

最新员工人数；

社保和公积金缴纳情况；

劳务派遣人数；

重大劳动争议；

报告期内大规模人员变化。

### 关联方和关联交易

新增关联方；

关联关系变化；

新增关联交易；

关联方注销、转让或者股权变化。

### 对外担保、借款和重大负债

新增担保；

新增重大借款；

担保解除；

债务违约；

重大融资安排。

这些事项本身就天然具有：

**“截至某一日期更新”**

的属性。

特别适合让Agent自动识别。

## 四、还要检查上一期有哪些“待核验事项”

更新报告期清单不能只看新发生的事情。

还要把上一期没有彻底解决的问题继续带进来。

比如上一期法律意见书写：

**【待补充某次增资出资凭证】**

或者：

**【待取得主管部门证明】**

或者：

**【某项许可证将于2026年5月到期，需持续关注续期情况】**

到了6月30日，

这些问题就应该自动进入新的尽调清单。

例如：

“请补充提供XX许可证最新续期文件。”

而不是因为进入了新的报告期，就把旧问题忘掉。

所以Agent生成新清单时，要同时读取上一版文件里的：

【待核验】

【待补充】

【持续关注】

以及相关批注。

## 五、尤其要检查“已经到期”的事项

这一点非常实用。

有些事情在上一期不是问题。

只是因为：

**时间还没到。**

比如上一期报告写：

“公司持有的XX许可证有效期至2026年5月31日。”

到了新的报告期：

2026年6月30日，

这张许可证已经过期了。

那么新的清单里就必须要求：

**“请提供XX许可证续期后的最新证照及续期申请材料。”**

同样包括：

租赁合同；

重大业务合同；

资质证书；

整改期限；

承诺履行期限；

知识产权有效期。

所以Agent最好把上一期资料里的关键期限统一扫描一遍。

凡是在：

**上一截止日之后、新截止日之前**

到期的事项，

自动进入补充尽调清单。

## 六、清单一定要写得具体，不要只写“请更新”

比如不要写：

“请更新公司诉讼情况。”

最好写：

“请提供2026年4月1日至2026年6月30日期间公司及其控股子公司新增诉讼、仲裁案件清单及相关起诉状、应诉通知、裁判文书、和解协议等材料，并说明上一报告期尚未完结案件的最新进展。”

也不要只写：

“请更新重大合同。”

而应该写：

“请提供2026年4月1日至2026年6月30日期间新签、续签、终止或发生重大变更的重大销售、采购、借款、担保、租赁等合同，并说明上一报告期重大合同目前的履行状态。”

这样企业收到以后才知道：

**到底要找什么。**

## 七、最好区分“必须提供”和“如有变化请提供”

更新报告期时，不是所有项目都一定发生变化。

所以可以把清单写成两种要求。

第一类：

**必须更新。**

比如：

最新员工人数；

最新社保数据；

最新诉讼情况确认；

最新关联方清单。

即使没有变化，也需要企业确认：

“截至2026年6月30日无变化。”

第二类：

**如有新增或变化，请提供。**

比如：

报告期内新取得土地；

新增行政处罚；

股权转让；

新增重大诉讼。

如果没有发生，

企业只需要明确回复：

“无新增。”

这样清单会更加高效。

## 八、清单里最好直接设置企业回复栏

可以做成这样的表格：

| 序号 | 核查事项 | 本次更新要求 | 更新期间 | 企业回复 | 对应文件 |
|---|---|---|---|---|---|
| 1 | 工商变更 | 请提供报告期内全部工商变更资料；如无变化请确认 | 2026.4.1—6.30 |  |  |
| 2 | 重大合同 | 请提供新增、续签、终止或重大变更合同 | 2026.4.1—6.30 |  |  |
| 3 | 诉讼仲裁 | 请提供新增案件及原有案件最新进展 | 截至2026.6.30 |  |  |
| 4 | 经营资质 | 请提供报告期内新取得、续期、变更或到期资质 | 截至2026.6.30 |  |  |

企业可以直接：

填写回复；

写“无变化”；

列文件名称。

后面Agent再读取这份表，就很容易继续做增量尽调。

## 九、尽量沿用原来的尽调清单编号

如果上一轮尽调清单已经有完整编号，

比如：

`1 公司基本情况`

`2 历史沿革`

`5 主要资产`

`7 重大合同`

`9 劳动用工`

新的报告期更新清单最好继续沿用这套编号。

例如：

`5.2 知识产权`

下面增加：

“请更新2026年4月1日至6月30日期间新增、转让、失效、许可或质押的知识产权情况。”

这样客户补回来以后，

材料可以继续直接归档到原来的：

`5.2-知识产权`

文件夹。

不用重新设计一套目录。

## 十、还可以让Agent先预测“这一次最可能变化的项目”

如果Agent已经了解当前项目，

它还可以进一步判断：

哪些模块本次应该重点更新。

比如一家：

高速扩张的制造企业，

可能重点关注：

新增厂房；

土地；

环保；

员工；

重大客户和供应商合同。

一家软件公司则可能重点关注：

知识产权；

研发人员；

数据合规；

软件许可。

所以更新清单不是机械复制标准模板。

应该结合：

**上一期项目情况 + 企业业务特点 + 上一期未决事项**

生成。

## 十一、这一步做完以后，再向企业正式要资料

所以报告期更新的第一阶段应该是：

确定原截止日  
↓  
确定新截止日  
↓  
Agent读取上一期尽调清单和法律文件  
↓  
识别所有动态事项  
↓  
扫描待核验事项和临近到期事项  
↓  
生成更新报告期尽调清单  
↓  
律师复核  
↓  
发给企业  
↓  
企业按清单补充材料

而不是：

新报告期一到，

直接告诉企业：

**“麻烦把最近的新资料都发过来。”**

## 十二、企业补资料回来以后，才进入下一阶段

等企业按照这份清单把材料补回来以后，

再进行下一步：

Agent读取新增底稿；

与上一期材料做差异比较；

调用工商、诉讼、知识产权、证券等MCP重新核查公开信息；

形成报告期变动清单；

制定补充法律尽调计划；

律师确认；

最后更新：

法律意见书；

补充法律意见书；

律师工作报告；

尽调报告；

其他申报文件。

这样整个报告期更新流程就会非常顺。

## 直接复制的实战提示词

请为本项目生成一份【更新报告期补充尽调清单.xlsx】。上一核查截止日为【原截止日期】，本次更新至【新截止日期】。请先阅读【上一期尽调清单、法律意见书/律师工作报告/尽调报告及相关底稿目录】，识别其中会随报告期变化的事项，以及上一期仍存在的【待核验、待补充、持续关注】和在本次新增期间内到期的资质、合同、承诺等事项。请严格沿用原尽调清单的序号和事项体系，逐项明确本次企业需要提供或确认的新增、变更、续期、终止及最新状态资料；不得简单重复上一期已经完整提供且本期无变化的历史资料。清单应包括“序号、核查事项、本次具体更新要求、更新期间、企业回复、对应文件”等字段，并区分【必须更新】与【如有变化请提供】。要求应具体到企业能够直接据此准备材料，避免使用“请提供相关资料”等笼统表述。完成后先提交律师复核，不要直接开始后续法律文件更新。

## 最后记住一句话

报告期更新真正的第一步，

不是：

**“开始更新法律意见书。”**

甚至也不是：

**“让企业把新资料都发过来。”**

而应该先问：

**“从3月31日到6月30日，哪些资料按性质就应该重新更新一次？”**

让Agent先把上一期项目重新看一遍，

生成一份有针对性的：

**更新报告期尽调清单。**

企业按清单提供资料以后，

后面的增量尽调和法律文件更新才真正有基础。
