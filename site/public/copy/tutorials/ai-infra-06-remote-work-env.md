# AI基建的第六步：搭一个远程工作环境，让AI可以一直干活

第六步：给自己搭一个随时能远程访问的 AI 工作环境。

以前是人坐在电脑前，电脑才干活。Agent 时代不一样：

**人可以走，AI 还得继续干。**

## 一、Agent 的活，往往不是几分钟的事

用 ChatGPT，提问、等几十秒、拿答案，结束。

Agent 不是。我会让它读完整个项目文件夹、检查几十份合同、整理几百个案例、批量处理 IPO 问询回复、下载整理公开资料、重建知识库索引、跑脚本清洗数据、处理几百份 PDF。

动辄半小时、一小时，甚至几个小时。

难道一直坐在电脑前等？没必要。

## 二、任务丢给 AI，人先走

先把任务设计好：材料在哪、要做什么、重点看什么、输出什么格式、结果存哪。

然后让它开跑。我去吃饭、开会、出门、休息，甚至睡觉。

隔一阵看一眼做到哪了。正常就继续，卡住就处理，完成了就检查。

AI 省的不只是写字的时间。更大的价值是：**它和人的时间可以并行。**

以前一项工作，我要连续投入两小时。现在是：我花 10 分钟布置，AI 干两小时，我花 20 分钟复核。中间那段，我去干别的。

## 三、人不在，怎么知道 AI 干到哪了

这就要靠远程控制。

比如早上在办公室给 Mac mini 丢个任务：

> 把这个项目里面2026年的全部问询回复重新整理一遍，生成索引并更新知识库。

然后出门。一小时后你会想知道：跑完没？报错没？卡在哪一步？要不要确认权限？Agent 是不是在等我回答问题？

配好远程控制，**掏出手机就行。**

看一眼桌面，Agent 还在跑，没问题。关掉手机，接着干自己的事。

## 四、手机是“AI 监工”

大任务在电脑上跑，手机不干活。

手机只管：看进度、处理弹窗、确认权限、补一句指令、出错时简单处理、确认有没有完成。

够了。

好用的 AI 工作系统，不该要求“我必须坐在这台电脑前”，而是：**只要电脑在线，我在哪都能看它。**

## 五、为什么我推荐 UU远程

我比较推荐 **UU远程**。

**无利益相关，纯粹是自己用下来觉得适合这个场景。**

我不拿手机剪视频，也不做复杂操作。需求就一个：**AI 在电脑上干活时，我能随时用手机看一眼。**

这个场景要的是：打开方便、手机端好操作、能看到完整桌面、必要时点几下、输几个字，然后关掉。对 Agent 完全够用。

UU远程在这件事上，我个人用着顺手。

## 六、远程控制的新用途：管理 Agent

以前说远程控制，是在家连办公室电脑，或者出差时临时开个文件。

AI 时代多了一个用途：**管理正在运行的 Agent。**

Codex 在跑长任务，Claude Code 在批量改文件，本地脚本在处理几千条数据，知识库在重建索引，MCP Server 在调试，GitHub 项目在部署。这些都得靠一台真电脑持续跑，但你没必要守着它。

远程软件做的，就是**把“人”和“AI 工作电脑”分开。**

## 七、这也是我推荐 Mac mini 的原因

办公室或家里放一台 Mac mini，长期插电、长期联网。装好 Codex、Claude Code、各种 MCP、GitHub、知识库、Python、Docker、Tailscale、各种自动化脚本。

平时不一定有人坐在它面前。它更像**一台 AI 工作站**。

> Mac mini负责长期运行  
> Agent负责干活  
> GitHub负责同步  
> MCP负责查资料  
> 手机负责看进度

整个系统就串起来了。

## 八、律师特别适合这种模式

律师**经常不在电脑前**：开会、见客户、开庭、出差、吃饭、在路上。

但 AI 的活可以接着跑。上午出门见客户前，先布置：

> 把这个项目全部材料检查一遍，重点找出关联交易和同业竞争问题，下午给我一个问题清单。

路上手机看一眼，正常。下午回来，第一轮结果已经出来了。

**电脑在线时间，也变成了生产时间。**

## 九、关键是别让电脑停下来

把 Agent 当长期生产力工具，注意这几件事：

- 保持稳定联网；
- 别让电脑自动休眠打断任务；
- 长任务期间接着电源；
- 远程软件提前配好；
- 别让系统更新突然重启机器；
- 长期运行的服务设成自动启动。

都是小事。但 Agent 跑了一小时，因为电脑睡眠断掉，会非常烦。

到这一步，你已经从**“用一个 AI 软件”**，转向**“维护一套 AI 运行环境”**。

## 十、再进一步：配上 Tailscale

设备多了以后，我喜欢用 Tailscale 这类组网工具，把 Mac mini、MacBook、VPS、其他电脑放进自己的虚拟局域网。除了远程桌面，还能 SSH、访问本地服务和 MCP、打开知识库、传文件、管服务器。

UU远程解决：**“我想看看这台电脑现在在干什么。”**

Tailscale 更像解决：**“我想让所有设备始终在同一个网络里。”**

刚起步没必要把网络搞复杂。先解决最现实的问题：**出门以后，还能不能看到 Agent。**

## 十一、远程控制也要讲安全

远程控制等于给电脑多开了一个外部入口。律师电脑里有客户材料、项目文件和其他敏感信息。至少做到：

- 使用强密码；
- 开启账号安全验证；
- 远程权限别随便给人；
- 重要设备做好系统登录保护；
- 不用的设备及时取消授权。

原则：**方便自己，但别为了方便无限扩大权限。**

## 十二、目标：机器时间和人的时间分开

别再以为 AI 干活时人必须陪着。

Agent 的工作本来就该异步：我布置任务，AI 开跑，我离开，手机偶尔看看，需要时介入，最后回来复核。

所以我的 AI 基建第六步是：**给自己的 AI 工作电脑，搭一套稳定的远程工作环境。**

电脑在线，Agent 干活，人可以走，需要时掏出手机看一眼。这个最简单、最实际的需求，我目前推荐用 **UU远程** 解决。

目的不是在手机上办公，而是：**AI 干活的时候，你不用一直陪着它。**

**你和 AI，已经不用同步上下班了。**
