# 庭前对抗演练与庭审提纲

> 民事诉讼 AI 实战系列·第五篇｜2026-08-27
> 适用阶段：开庭前两周至开庭当日
> **本篇默认你已读过《诉讼 AI 工作总则》**——能力边界、反编造纪律、期限盯守三条规则都在那里，本篇不再重复。

---

## 一、这一步真正难在哪

庭前最大的风险不是"没准备好"，是**"只按自己的思路准备好了"**。

代理思路在脑子里跑了二十遍，每一遍都是自己说服自己。开庭时对方律师提出一个你从没想过的抗辩，法官问一个你没准备的问题，当庭的反应时间只有几秒。这不是知识问题，是**视角单一**的问题。

传统解法是找同事对练，但同事读完卷宗要半天，还未必比你更熟案情。AI 多角色演练解决的正是这个：**几个互不通气的角色，各自读完全部案卷，站在自己的立场上，对你发起真实的攻击。**

**演练要有用，前提是"真"。** 上一版本要求先做一份脱敏案情摘要再交给各角色，这是错的——摘要是你自己写的，你写摘要时已经把"你认为重要的"筛了一遍，对方律师拿到的是你的视角，攻击自然打不到你的盲区。**真实的对方律师拿到的是全部案卷，不是你的摘要。** 所以本篇的做法是：**把全部材料原样交给每个角色**，包括合同原件扫描件、往来函件、对方已提交的全部文书与证据、我方证据目录与质证意见表。

保密不是靠删材料实现的，是靠**在哪台机器上跑**实现的——见下一节。

至于提纲，难点很实际：**庭审是有法定顺序的，提纲必须按那个顺序排。** 按自己的逻辑排的提纲，庭上翻不到。

---

## 二、开工前必须先有什么

**原则：给全部，不给摘要。**

| 材料 | 说明 |
| --- | --- |
| 全部案卷 | 起诉状／答辩状、合同与全部附件、往来函件、履行凭证、鉴定意见 |
| **对方已提交的全部文书与证据** | 这是对抗性的来源。只给我方材料的演练必然失真 |
| 我方证据目录与要素登记表 | 第二篇产出 |
| 质证意见表与举证方案 | 第四篇产出 |
| 庭审信息 | 法院、案号、开庭时间、程序（一审／二审）、独任或合议、承办法官（如已知）、预计时长、是否线上开庭 |
| 我方代理思路 | 一段话；**只给主对话，不给对方律师与法官角色** |

**唯一不给角色的是我方的代理思路和底牌。** 对方律师角色如果知道你打算怎么应对，就演不出真实的攻击。

### 保密怎么处理

保密要求解决的是"**在哪台机器上跑**"，不是"给不给全部材料"。按《总则》第二节的三级分类：

- 案卷含**一级材料**（身份证件、银行流水、未公开交易文件、鉴定意见原件、商业秘密载体）的，整个演练**在本机进行**——本地 OCR、本地模型或断网环境，不经任何云端解析服务；
- 案卷全部为**二级及以下材料**的，可上云，但当事人名称等身份信息按本所惯例处理；
- **不因为要上云就把材料删减后再演练**。宁可整场演练放在本机、用较弱的本地模型，也不要用一份阉割过的摘要去演一场假的庭审。

## 三、演练怎么搭：角色互不通气，各自读全卷

关键在"互不通气"。**在同一个会话里让 AI 依次扮演三个角色，它会不自觉地让三个角色互相配合**——对方律师提的抗辩恰好是你能应对的，法官问的问题恰好是你准备过的。这样的演练毫无价值。

正确做法：**每个角色开一个独立的子代理或独立会话，各自读全部案卷，彼此看不到对方的输出。**

| 角色 | 给它什么 | 让它产出什么 |
| --- | --- | --- |
| **对方代理律师** | 全部案卷（不含我方代理思路） | 抗辩策略、逐份质证意见、发问设计、突袭方案 |
| **承办法官** | 全部案卷（不含任何一方的内部思路） | 争议焦点归纳、双方发问、依职权查明事项、心证倾向 |
| **对方当事人本人** | 全部案卷 | 非专业但可能打乱节奏的表达、当庭情绪反应 |
| **审判长（模拟开庭用）** | 全部案卷 | 按法定顺序主持整场庭审 |
| **验收员**（新会话，换模型更好） | 演练全部产出 | 复核有无自说自话、有无无依据的法条援引、遗漏了哪些攻击角度 |

### 3.1 对方代理律师（独立子代理）

```text
你是【乙公司】的代理律师，立场与对方（甲公司）完全对立。你的当事人希望你尽全力。
材料：本案全部案卷，路径【】。你可以逐份查阅，包括合同、往来函件、
履行凭证、对方证据目录及全部证据材料、鉴定意见。

输出：
1. 你方最可能的三套抗辩策略，事实抗辩、法律抗辩、证据抗辩各至少一套。
   每套写明：核心主张｜依托的具体材料（写到文件名与页码）｜预期效果｜
   对方最可能如何回应，你再如何应对；
2. 对甲公司每份证据的质证意见，按真实性、合法性、关联性、证明力四栏。
   重点标出你认为最容易打掉的三份，写明打击点落在证据的哪一处
   （具体到页码与位置，例如"证据5第2页无骑缝章"）；
3. 你会向法庭申请查明的事实、申请调取的证据、申请鉴定的事项；
4. 你认为甲公司举证最薄弱的三处，各写明你打算怎么利用；
5. 你在庭审中最想问甲公司当事人和证人的五个问题，
   每个问题写明：你想得到什么答案｜对方若这样答你如何追问｜
   对方若那样答你如何追问；
6. 你的突袭方案：你打算当庭提交什么、当庭提出什么新抗辩、
   选择在哪个环节抛出、预期造成什么效果。

要求：专业、有攻击性，不要客套，不要替对方（甲公司）说话，
不要给出"双方各有道理"这类中立表述。
纪律：你援引的任何法条、案例都标注"（演练援引，未核验）"，不得作为定论；
你对材料的引用必须真实——只引案卷中实际存在的内容，写明文件名与页码，不得虚构。
```

### 3.2 承办法官（独立子代理）

```text
你是本案承办法官，案由【】，法院层级【】，程序【一审／二审】，
【独任审理／合议庭审理】。材料：本案全部案卷，路径【】，双方提交的材料你都已阅。

输出：
1. 你归纳的本案争议焦点，按你的审理习惯排序，说明排序理由；
2. 你会向原告、被告各提三个问题，写明提问目的与你想验证什么；
3. 你认为双方举证均未覆盖、需要依职权查明或向当事人释明的事项；
4. 心证倾向提示：以现有材料，哪些事实主张缺乏证据支撑，
   哪些证据你会重点核对原件；
5. 你会要求哪些证据出示原件、哪些电子数据要求当庭演示；
6. 你认为本案有无调解空间，如有，切入点在哪。

纪律：不作结论性裁判意见；援引法条标注"（演练援引，未核验）"；
对材料的引用写明文件名与页码，不得虚构。
```

### 3.3 完整模拟开庭（本篇核心，独立子代理扮审判长）

前两个角色出的是"策略清单"，这一步出的是**一场真实节奏的庭审**。按《民事诉讼法》第一百四十一条、第一百四十四条的法定顺序走完。

```text
你是本案审判长。材料：本案全部案卷，路径【】。
现在主持一场完整的模拟庭审，你同时扮演审判长与被告代理人，我扮演原告代理人。
一次只推进一个环节，说完等我回应再继续，不要替我作答，不要一次演完。

按下列法定顺序进行：
一、法庭调查
   1. 当事人陈述：先请原告陈述诉讼请求与事实理由，再请被告答辩；
   2. 证人作证（如有）：告知权利义务，证人陈述，双方发问；
   3. 出示证据：请原告举证，被告质证；再请被告举证，原告质证。
      质证时你要按真实法庭的节奏推进，被告的质证意见要具体到证据的哪一处，
      不得只说"三性不认可"；
   4. 宣读鉴定意见（如有）；
二、法庭调查中你作为审判长的发问：在你认为必要的节点插入发问，
    并对你认为需要释明的事项作出释明；
三、法庭辩论：按原告发言—被告答辩—互相辩论的顺序进行，至少两轮；
四、最后陈述：按原告、被告的顺序征询最后意见；
五、闭庭后输出《模拟庭审复盘》：
   1. 我方在哪些环节反应不足、答非所问、被带偏；
   2. 被告的哪些攻击我方没有当场化解；
   3. 你作为审判长在庭上形成的初步心证及其形成节点；
   4. 我方遗漏的当庭申请（补充举证、鉴定、原件核对、质证期限、
      请求记明笔录等，见第四篇六类情形）；
   5. 时间分配问题：哪个环节用时过长、哪个环节仓促。

纪律：全程按真实庭审的语气与节奏，不作解说式旁白；
被告的攻击要真实有力，不得为了让流程顺畅而放水；
援引法条标注"（演练援引，未核验）"；引用材料写明文件名与页码，不得虚构。
```

**这一步的价值**在于它暴露的不是"我想漏了什么法律问题"，而是**"我在庭上的反应有多慢"**——策略清单看不出这个。

### 3.4 对抗轮次（主对话）

```text
基于对方律师的策略、法官的关注点和模拟开庭的复盘，进行两轮对抗推演：
第一轮：我方对对方三套抗辩逐套给出应对（补证／法律反驳／让步空间），
       对法官的每个问题给出回答口径（每条不超过三句）；
第二轮：假设对方拿到我方第一轮应对后升级攻击，我方再应对。
每轮结束输出《我方薄弱点变化表》：薄弱点｜第一轮状态｜第二轮状态｜
是否已消除｜未消除的补强动作、责任人与期限。
```

### 3.5 验收（新会话，换模型更好）

```text
你是验收员。下面是一次庭前对抗演练的全部产出【粘贴】，案卷在【路径】。
不要重做演练，只做五件事：
1. 找出"自说自话"的地方——对方律师的攻击恰好是我方能轻松应对的，
   或法官的问题恰好落在我方准备好的答案上；
2. 逐条核对演练中对案卷材料的引用是否属实（文件名、页码、内容），
   引用不实的单独列出；
3. 找出全部法条与案例援引，逐条标注"已核验／未核验／疑似不存在"；
4. 指出演练遗漏的攻击角度——对方还可能从哪里打；
5. 输出"演练可信度评估"：哪些结论可以采纳，哪些需要重做。
```

## 四、庭审提纲：按法定顺序排

提纲的结构不能自己发明，要对着法定的庭审顺序排。

**《民事诉讼法》第一百四十一条**规定法庭调查按下列顺序进行：（一）当事人陈述；（二）告知证人的权利义务，证人作证，宣读未到庭的证人证言；（三）出示书证、物证、视听资料和电子数据；（四）宣读鉴定意见；（五）宣读勘验笔录。

**第一百四十四条**规定法庭辩论按下列顺序进行：（一）原告及其诉讼代理人发言；（二）被告及其诉讼代理人答辩；（三）第三人及其诉讼代理人发言或者答辩；（四）互相辩论。法庭辩论终结，由审判长或者独任审判员按照原告、被告、第三人的先后顺序征询各方最后意见。

```text
汇总【证据目录】【举证方案】【质证意见表】【模拟庭审复盘】，
生成《庭审提纲》，格式紧凑可打印，单页信息密度优先，按下列结构：

一、开庭前速查（第一页顶部）
   案号｜法庭｜时间｜独任或合议｜对方代理人｜我方携带原件清单｜今日必须完成事项

二、法庭调查阶段（对应民诉法第 141 条顺序）
   1. 当事人陈述：3 分钟版提词，逐句可念；诉讼请求逐项复述（金额精确到元）；
   2. 法庭可能对我方当事人的发问 + 建议回答口径（接法官角色的问题清单），
      每条口径不超过三句话；
   3. 对对方当事人／证人的发问清单：每个问题标注提问目的、预期回答、
      对方若否认时的追问路径（至少两条分支）；
   4. 我方举证：直接引用第四篇《举证方案》的分组与三句话说明卡，
      不重新编写。

三、举证质证阶段
   1. 质证意见速查表：按对方证据编号排列，每份一行，
      仅保留结论与一句话理由（完整版留在质证意见表里，不进提纲）；
   2. 重点质证的五份：单独一栏，写明打击点（具体到页码位置）与预期效果；
   3. 需要求出示原件的证据清单；
   4. **当庭六类情形的应对表述**：直接引用第四篇的表述卡，
      打印后夹在本页背面。

四、法庭辩论阶段（对应民诉法第 144 条顺序）
   逐个争议焦点一张"1 分钟观点卡"：焦点｜我方结论｜三个论据（各附证据编号）｜
   对方最可能的反驳与我方回应。

五、最后陈述
   30 秒要点，三句话以内。

六、闭庭前清单
   笔录必须核对的四类内容（当庭申请／原件核对记明／法庭释明／对方自认）｜
   庭后期限（代理词提交｜补充证据｜鉴定费预交｜补充举证）

纪律：
- 提纲中每一处法条引用标注是否已核验；未核验的当庭不引；
- 演练中的推测性结论不写入"事实"部分，只放在"预案"部分；
- 金额、日期一律与证据目录一致，不重新计算；
- 全篇控制在 4 页以内。
```

## 五、庭前提醒：五级设置

按《总则》第五节的三条规则建任务：一个任务管一件事、写清最终动作与收件人、无变化也简报。

| 时点 | 提醒内容 |
| --- | --- |
| 开庭前 7 日 | 准备期检查：提纲是否成稿、演练是否完成、补强证据是否到位、证人是否确认出庭 |
| 开庭前 3 日 | 举证期限、补充证据期限是否届满；需申请延期的现在提；鉴定费是否已预交 |
| 开庭前 2 日 | 证人到庭确认、当事人到庭确认、线上开庭的设备与网络测试 |
| 开庭前 1 日 | 原件核对（逐份对照需核原件清单）、电子数据演示设备检查、材料装袋、提纲打印 |
| 开庭当日 8:00 | 出发提醒，正文含法庭位置、时间、携带清单 |

**日期纪律**：所有提醒的基准日以**传票记载**为准，AI 推算的日期一律标"（推算）"。开庭时间变更后第一件事是重设全部提醒——变更通知到了而提醒没改，是很常见的事故。

## 六、AI 在本环节的典型出错方式

| # | 错法 | 识别信号 | 处置 |
| --- | --- | --- | --- |
| 1 | **角色互相配合**：对方律师的攻击恰好是我方准备好的 | 演练读起来"很顺"；第一轮应对就消除了全部薄弱点 | 角色必须开独立会话；跑验收员复核 |
| 2 | **只给部分材料导致演练失真** | 对方律师的抗辩没有引用到对方自己提交的证据 | 全部案卷原样投喂，不做摘要、不做删减 |
| 3 | **我方代理思路泄给了对方角色** | 对方律师的输出里出现我方的应对逻辑 | 代理思路只进主对话 |
| 4 | **对方律师太客气**：抗辩温和、留有余地 | 出现"可能""或许""建议协商""双方各有道理" | 明确要求攻击性；不满意换模型重跑 |
| 5 | **虚构案卷内容**：引用了案卷里没有的文件或页码 | 引用的文件名在案卷中不存在；页码超出实际页数 | 验收员逐条核对引用属实性 |
| 6 | **演练法条当真**：把角色援引的法条写进提纲或代理词 | 提纲里的法条没有核验标记 | 演练援引一律标"（演练援引，未核验）"；进对外文书前回官方来源重核 |
| 7 | **案例幻觉** | 案号格式完美但检索不到 | 验收员专项核查；检索不到即删 |
| 8 | **模拟开庭变成解说** | 出现"接下来进入法庭辩论阶段，这一阶段的意义是……"这类旁白 | 要求全程按真实庭审语气，不作解说 |
| 9 | **模拟开庭一次演完** | 一次性输出整场庭审，我方没有回应机会 | 一次只推进一个环节，等回应再继续 |
| 10 | **提纲按自己的逻辑排** | 提纲结构与第 141、144 条顺序不一致 | 按法定顺序重排 |

| 16 | **把演练结论当案件评估** | 出现"经演练，我方胜诉可能性较大" | 演练不产出胜诉判断；删除 |
