# AI实战05｜让Agent直接处理Excel：不要只让AI给你一张Markdown表格

很多人让AI处理表格时，最后得到的是：

一张聊天框里的Markdown表格。

然后还要自己：

复制到Excel；

调整列宽；

补公式；

整理格式；

重新保存。

如果Agent已经能够直接操作文件，这种方式其实没有必要。

更好的方法是：

**直接把Excel文件交给Agent，让它在真实表格里完成工作。**

## 一、Excel任务不只是“生成一张表”

真正的Excel工作通常包括：

读取已有数据；

清洗格式；

合并多个工作表；

提取字段；

计算数据；

增加公式；

筛选异常；

生成汇总表；

甚至制作图表。

这些工作如果只停留在聊天框里，实际价值会打折。

所以任务应该从：

“帮我列一张表”

变成：

**“把这个Excel处理好。”**

## 二、先告诉Agent：哪些数据不能动

Excel和Word不太一样。

很多表格里可能存在：

公式；

隐藏列；

多个Sheet；

数据验证；

特定格式。

所以处理已有Excel时，最好明确：

哪些Sheet需要处理；

哪些列可以修改；

哪些原始数据不能改。

尤其是涉及财务、项目台账等数据时，建议：

**保留原始数据Sheet，在新的Sheet里生成整理结果。**

这样更安全，也方便复核。

## 三、数据整理最适合让Agent统一规则

比如你有一张合同台账，但格式很乱。

有的金额写：

100万元。

有的写：

1,000,000。

有的日期是：

2026/8/1。

有的是：

2026年8月1日。

可以让Agent统一：

日期格式；

金额格式；

公司名称；

空值标记；

分类字段。

这类重复、规则明确的数据清洗，非常适合AI。

## 四、不要让AI偷偷“猜数据”

这是Excel处理特别需要注意的地方。

比如某一行：

合同金额为空。

AI不能因为上下文里看起来应该是100万元，就直接补进去。

更合理的是：

**原始数据没有，就保留为空或者标记“未明确”。**

数据任务里：

准确性通常比“表格看起来完整”更重要。

## 五、公式和计算最好留在Excel里

比如需要计算：

合同剩余期限；

金额合计；

增长率；

占比；

风险数量。

如果可以用Excel公式完成，最好直接让Agent写进单元格。

这样以后数据变化时，结果还能自动更新。

而不是让AI算出一个固定数字写进去。

所以处理Excel时，可以要求：

**能够使用公式的计算，优先使用公式，不要只写死结果。**

## 六、多张表可以先合并，再分析

真实工作里经常有：

1月.xlsx；

2月.xlsx；

3月.xlsx。

或者：

客户A；

客户B；

客户C

分别一个Sheet。

这时候Agent可以先按照统一字段：

合并数据；

清理重复；

保留来源；

再进行分析。

最好增加一列：

**来源文件 / 来源Sheet。**

这样以后发现数据异常，可以快速回到原始位置。

## 七、Excel特别适合做“中间工作底稿”

前面讲批量文件时已经提到：

大量材料最好先结构化。

Excel就是非常适合的中间载体。

比如律师做IPO案例整理，可以把每个案例先提取成一行：

公司；

板块；

问题；

回复逻辑；

整改措施；

来源。

以后：

筛选；

比较；

统计；

补充新案例

都会非常方便。

所以AI生成Excel，不只是为了“看起来整齐”。

更重要的是：

**把非结构化材料变成可以继续处理的数据。**

## 八、最后一定要检查文件是不是真的能用

Agent说：

“Excel已经生成。”

并不代表任务结束。

至少应该检查：

文件能不能打开；

列是否错位；

公式是否报错；

是否漏Sheet；

原始数据是否被改动；

数字格式是否正确。

所以Excel任务最后最好要求Agent自己做一次基本检查。

## 直接复制的实战提示词

请处理【Excel文件/文件夹绝对路径】。根据【具体任务】整理其中的数据，重点完成【字段提取、清洗、合并、计算、分类或统计要求】。请保留原始数据，不得擅自补充缺失信息；能使用Excel公式实现的计算优先保留公式，并保留数据来源。最终生成【整理后的Excel文件】，保存至【输出文件夹】，不得覆盖原文件。完成后检查Sheet、公式和关键数据是否正常，并列明需要人工确认的异常项。

## 最后记住一句话

如果最终成果本来就是Excel，

就不要让AI只在聊天框里：

**“给你一张表。”**

而应该直接让Agent：

**读取真实数据、处理真实表格、生成可以继续工作的Excel文件。**

这才是AI真正进入数据工作的开始。
