# 用AI做一个自己的公众号排版模板：四步搞定，附全部提示词

我现在的公众号文章排版，基本不花时间。

不是我买了什么排版工具，而是我让AI给我做了一个**专属排版模板**：文章写完，转成Markdown丢进去，出来一个网页，点一下「复制」，粘贴进公众号编辑器，标题、配色、卡片、金句、二维码全部就位。

这件事一次做好，以后每篇都省时间。这篇文章把整个过程拆成四步，每一步的提示词我都写出来，你可以直接用。

## 一、先让AI「看」一个你喜欢的样子

做模板最难的其实不是写代码，而是「说清楚我想要什么风格」。

解决办法：不用凭空描述，找一个你喜欢的网站（或一篇排版好看的文章），把链接发给AI，让它先把视觉规范提取出来。

**提示词①：提取设计语言**

```
打开这个网站：https://你的参考网站.com
请分析它的视觉风格，输出一份「设计规范」，包括：
1. 主色、辅色、背景色（给出色号）
2. 标题、正文、小标签的字体和字号层级
3. 卡片、按钮、引用块等组件的样式特点
4. 整体的版式气质（用三个词概括）
输出成一份清单，我之后要拿它做公众号排版模板。
```

AI会给你一份类似「主色 #0e6f3f 深绿、背景 #f4f7ef 浅绿白、圆角卡片、等宽字体小标签」的清单。这份清单就是模板的「图纸」。

## 二、让AI生成第一版模板

关键来了：公众号编辑器和普通网页不一样，直接写的网页粘进去会散架。所以提示词里必须交代三个硬约束：

- **所有样式写在内联style里**——公众号粘贴时会把CSS样式表剥掉，只有写在每个标签上的样式能活下来；
- **不用外部资源**——不引外部字体、图片、CSS文件，否则粘贴后失效；
- **加一个「一键复制」按钮**——复制的是渲染后的正文，而不是代码。

**提示词②：生成模板**

```
根据下面的设计规范，帮我做一个微信公众号排版模板，要求：

【设计规范】（粘贴第一步的清单）

【硬约束】
1. 正文所有样式必须内联（style属性），不用<style>标签、不引用任何外部资源；
2. 用section/p/span组织结构，间距优先用padding；
3. 页面顶部加一个「一键复制全文」按钮：点击后复制正文区域HTML，我去公众号编辑器直接粘贴；
4. 模板里放这些占位区块：文章头部（标签胶囊+主标题+作者）、正文段落、金句卡片、列表卡片、结尾、底部签名；
5. 正文区用手机宽度预览（约414px）。

先给我完整HTML文件。
```

拿到HTML文件，浏览器打开，你的第一版模板就出现了——大概率不完美，正常。

## 三、像验收工作一样提修改意见

接下来就是看效果、提意见、让AI改。提意见别写「不好看，改一下」，要像给下属提验收意见一样具体：

**提示词③：迭代修改**

```
浏览器打开效果我有几条修改意见：
1. 主标题太大，从28px降到24px；
2. 金句卡片改用白底+左侧4px绿色竖条，字加粗；
3. 正文行高加大到1.9，两端对齐；
4. 复制按钮换到顶部居中。
改完重新给我完整文件。
```

一般改三轮以内就满意了。这轮的产出是：一个你完全满意的HTML模板文件。

## 四、把模板「存下来」，变成以后随手的资产

到这一步，多数人会把模板文件存到桌面，下次用的时候再翻出来。更好的做法是把它变成AI的固定技能：把最终版模板交给AI，连同使用规则一起存档。

**提示词④：固化为可复用模板**

```
这是我定稿的公众号排版模板（附HTML）。
请帮我把它固化成可复用的资产，并写一份使用说明，包括：
1. 每个区块对应什么内容，哪几个必须保留，哪些按文章情况选用；
2. 以后我发你一篇Markdown文章时，你按模板填充、不改文字，输出成品HTML；
3. 文件命名规则：公众号排版-日期-版本-主题。
```

如果你用的是支持Skill/自定义指令的AI工具，让它把这份说明存成一条固定技能；如果是普通对话工具，把这段说明和模板存进备忘录，每次开新对话先粘贴给它。

从此，排版这件事的工作流就变成了：**写文章 → 丢给AI → 点复制 → 粘贴进公众号。**

## 写在最后

这件事给我最大的启发不是「AI能写代码」，而是：

**一次把规则讲清楚，以后就不用重复讲。**

排版是这样，审合同的偏好是这样，写作的格式要求也是这样。你重复做过三次的事情，就值得让AI把它变成一套固定流程。
