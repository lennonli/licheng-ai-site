# AI基建的第三步：不是广告，但 Apple 电脑真的比 Windows 好用

第三步，说电脑。结论有点主观，但越折腾越确定：

**准备长期把 AI 当生产力工具，尤其要用 Agent、MCP、GitHub、Python、Docker、Tailscale、本地脚本，我优先选 Mac。**

不是广告，也不是说 Windows 不能用。是现在这套 AI 工具生态里，Mac 更省心。

## 一、现在选电脑，要看 AI

以前律师的电脑就是 Word、Excel、PDF、微信、浏览器、邮箱，两边都能干。国内不少办公软件、电子签章、银行和政务系统围着 Windows 开发，用 Windows 很正常。

AI 来了，情况变了。我的电脑现在要装 Agent、跑 Python 和 Node.js、用 Git 和 GitHub、调 API、配 MCP、跑本地服务、SSH 连 VPS、跑 Docker、用 Tailscale，还要让 AI 自己读写文件、执行命令、改配置。

它已经不是办公终端，而是：

**AI 的本地工作环境。**

## 二、Mac 开箱就是好用的开发环境

别看到"开发环境"就觉得跟律师无关。进了 Agent 时代，不会写代码也天天碰命令行：装 MCP、跑 GitHub 项目、配环境变量、装 Python 包、SSH 登 VPS。

Mac 底层是 Unix。面向开发者的 AI 工具，在 Mac 上装和用都很自然。打开 Terminal，Git、SSH、Python、Node、Homebrew 一下就串起来。

有了 Agent，你不用懂每条命令，直接说：

> 帮我把这个 GitHub 项目安装到这台 Mac 上，安装前检查环境，遇到问题自己解决，最后测试能不能正常运行。

Mac 就是 AI 的"施工现场"。

## 三、AI 工具天然偏向 Mac/Linux

很多新 AI 工具，最先支持的就是 Mac、Linux、命令行。Windows 有 WSL，方便多了，但：

**多一层，就多一层复杂度。**

教程写"打开 Terminal → 输入命令 → 完成"。到了 Windows，先得想：PowerShell、CMD、Git Bash 还是 WSL？文件在 Windows 目录还是 Linux 目录？路径怎么一个 `C:\` 一个 `/mnt/c/`？

程序员不当回事。但我是律师，搭 AI 基建不是为了学操作系统，是为了：

**少折腾环境，赶紧让 AI 干活。**

## 四、适合"不会编程，但敢让 AI 编程"的人

不会写代码，让 AI 写。不会 Linux，让 Agent 操作 VPS。于是有了一类新用户：

**自己不是程序员，但天天用程序员的工具。**

这类人最适合 Mac。你只管三件事：说清要什么，给 Agent 足够权限，检查结果。"把这个 MCP 装好""每天自动同步一次""查一下这个端口为什么访问不了"——这些活交给 Agent。Mac 给 Agent 的是一个标准、统一、好操作的环境。

## 五、内存和硬盘，往大了买

只做 Word，16GB 内存够了。搭 AI 工作系统，预算允许就：

**内存和硬盘尽量往大了买。**

浏览器几十个标签，ChatGPT、Claude、Codex、Word、VS Code、Docker、本地知识库、多个 MCP、后台同步同时开着，是常态。GitHub 仓库、Docker 镜像、模型缓存、OCR 文件、备份、向量数据库，只会越堆越多。

**CPU 不必追顶级，内存和存储留足余量。** Apple 买后基本没法加内存，下单前想清楚。

## 六、Mac mini 适合做 AI 常驻主机

有 MacBook 的，不一定再买贵的 MacBook Pro，Mac mini 值得考虑。体积小，功耗低，能长期在线。

MCP Server、知识库、自动化脚本、GitHub 同步、本地数据库、Tailscale 节点、定时任务，都放上面跑。MacBook 关机，它照样在线，慢慢就成了：

**家里或办公室的一台 AI 基础设施服务器。**

## 七、Windows 不是不能用

国内办公软件、行业软件、网银、电子签章、政府系统，Windows 兼容性可能更好；Office 一些高级功能也可能更全。手里有台好 Windows，没必要为 AI 马上换，WSL 也解决了不少问题。

所以我不是说"Windows 不能做 AI"，而是：

**让我从零搭一套个人 AI 工作环境，我优先买 Mac。**

## 八、电脑决定你每天折不折腾

大模型决定 AI 想不想得明白，智能体决定能不能做出来，电脑决定：

**你每天用这一套顺不顺手。**

今天装 Agent，明天加 MCP，后天跑 GitHub 项目。每加一个工具都先搞半天环境，用不了多久你就不想用了。

**AI 基建要紧的不是配置豪华，而是摩擦够小。**

打开电脑，Agent、Terminal、项目、Git、MCP、Tailscale 都在。告诉 AI 做什么，它就开工。

我喜欢 Mac，不是因为 Logo。是因为进了 Agent 时代，**一台稳定、统一、Unix 原生、适合 AI 和开发者工具运行的电脑，确实少折腾很多。**

所以第三步：**预算允许，给自己配一台配置宽裕的 Apple 电脑。**

尤其是准备长期用 Agent 的人。

**电脑买回来不是跑分的，是让 AI 在里面长期干活的。**
