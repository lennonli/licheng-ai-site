# AI基建的第九步：做好备份，别让你的AI工作系统一夜归零

AI 工作系统搭到这一步，要备份的已经不只是工作文件了。

以前电脑坏了，担心的是 Word、PDF、照片。现在可能丢的，还有 Skill、Prompt、MCP 配置、知识库、脚本、Agent 配置、GitHub 项目、VPS 数据库，以及花几个月调顺的整套工作环境。

原则就一句：

**机器可以坏，系统可以重装，但重要数据不能只有一份。**

## 一、要备份的是“生产能力”

我把合同审查方法整理成一个 Skill，前后花了几个月。一开始只是几条提示词，后来不断补：什么情况必须核验法律依据，怎样坚持客户立场，怎样最小必要修改，怎样输出修改说明，Word 怎么排版。

这个 Skill 如果只存在本地，电脑一坏：

**几个月的调教一起没了。**

知识库也一样。几千个案例做了分类、标签、索引，值钱的早就不是原始 PDF，而是后面的整理工作。

**AI时代要备份的是“生产能力”，不只是文件。**

## 二、Skill、脚本和配置，放GitHub

第五篇讲 GitHub，这是重要原因之一。

Skill、Prompt、Markdown 知识库、自动化脚本、MCP 配置模板、部署脚本、项目说明，都适合放 GitHub。

本地改完提交一次。MacBook 一份，Mac mini 一份，GitHub 云端一份。电脑坏了，重新拉下来就行。

还有个好处：**历史版本也在。** Skill 改坏了，直接回退，不用靠记忆恢复。

## 三、客户文件别因为方便就扔GitHub

客户合同、尽调底稿、诉讼材料、身份证件、内部法律意见、未公开交易资料，不适合按“代码备份”的思路处理。

我的做法是分开：

**方法和系统，放 GitHub。**

**客户原始资料，按律师文件管理和保密要求单独备份。**

本地硬盘、合规云存储、NAS 或律所已有的文档系统都行。别为了 AI 用着方便，把原来的保密边界打乱。

## 四、Mac：把Time Machine用起来

Mac 自带最省事的方案：**Time Machine。** 一块移动硬盘或 NAS，定期备份。

它的意义不在某个文件，而是把本地环境整体留住。电脑坏了、误删文件、Agent 改坏一批资料、换新 Mac，恢复都轻松很多。

Agent 现在能建文件、批量改、挪目录、删内容。能力越强，误操作波及面越大。

**给 Agent 较高文件权限之前，先把备份做好。**

## 五、VPS不是“永久硬盘”

讲 VPS 时说过：**服务器可以丢，数据不能丢。**

VPS 是租来的电脑。忘记续费、支付失败、账号异常、云厂商故障、误删实例、硬盘损坏，都可能让整台机器消失。

所以：知识库数据库定期导出，重要代码同步 GitHub，配置文件留副本，必要时做服务器快照。

目标是：**今天这台 VPS 没了，明天换一台还能重新部署出来。** 服务器只是运行环境，不是唯一的数据仓库。

## 六、重要内容至少三份

备份不用设计得很复杂。记住一条：**重要内容至少三份。**

- Skill：Mac mini、MacBook、GitHub 各一份。
- 重要客户项目：工作电脑一份，备份硬盘或 NAS 一份，合规的异地备份一份。
- VPS 数据：服务器在用一份，定期导出一份，另一个位置再存一份。

唯一要避免的是：**唯一的那份，恰好在那台会坏的机器里。**

## 七、账号和恢复信息也别漏

系统跑起来后，会牵涉 GitHub、云服务器、域名、Cloudflare、模型 API、数据库、各种 MCP 服务。只记在脑子里，就是风险。

至少用一个安全的密码管理工具，存账号、密码、恢复码和必要的服务器信息。

但 API Key、Token、SSH 私钥，不能明文扔进 GitHub。

备份不是“所有东西复制到一个文件夹”，而是不同数据用不同方法存。

## 八、检验标准：换台电脑能不能快速恢复

测试很简单：今天这台 Mac 坏了，换台新的，你能不能较快恢复 Agent、Skill、MCP、GitHub 仓库、知识库、常用脚本、服务器连接和工作环境？

“完全不记得装过什么，只能重新折腾”——说明系统还没沉淀下来。

登录账号、拉 GitHub、恢复备份、装几个核心软件就能接着干——这套基建才算稳了。

## 九、备份保护的是你积累的AI能力

第九步就是：**把备份做好。**

Mac 做系统级备份。Skill、脚本、配置用 GitHub 管。VPS 重要数据定期导出。客户文件按保密要求单独存。重要内容不只一个副本。

电脑坏了可以买，VPS 没了可以租，模型也能换。但几个月甚至几年沉淀下来的知识库、Skill、工作方法和整套 AI 工作系统，因为没备份一次丢光，就太可惜了。

**机器可以丢，系统可以重装，数据和积累不能丢。**
