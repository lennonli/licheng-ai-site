# AI实战19｜100页尽调报告怎么看？让Agent提炼重大问题清单

一份法律尽调报告做到后面，可能有：

几十页；

上百页；

几万字。

但真正给客户、项目负责人或者合伙人汇报时，对方通常不会先从第一页开始完整阅读。

他们更关心的是：

**这个项目到底有什么重要问题？**

所以尽调报告基本完成以后，我通常会再让Agent做一项工作：

**从整份报告里提炼一份重大问题清单。**

不是重新写一份摘要。

而是专门把：

可能影响交易的事情

挑出来。

## 一、重大问题清单不是“尽调报告摘要”

如果只是告诉Agent：

“帮我总结这份尽调报告。”

最后很可能得到：

公司基本情况如何；

历史沿革如何；

主要资产如何；

重大合同如何；

劳动用工如何。

这其实只是把100页报告压缩成10页报告。

真正需要的是：

**哪些问题值得决策层关注。**

所以任务应该明确：

不要平均总结每个章节。

只提取：

重大风险；

重要异常；

尚未解决的问题；

可能影响交易的事项；

需要进一步处理的事项。

## 二、先从报告里找“问题”，而不是找“内容”

比如报告里写：

“公司共有专利38项。”

这通常只是事实。

但如果写：

“公司核心产品所使用的3项专利登记在实际控制人个人名下。”

这就可能是一个需要重点关注的问题。

所以Agent提炼时，要把大量正常事实过滤掉。

真正关注：

**什么事情可能改变交易判断。**

## 三、可以把问题分成几个类型

### 交易前需要解决

如果不解决，可能不适合直接交割。

例如：

核心资产权属存在重大瑕疵；

重要资质即将到期；

关键股权存在争议。

### 交易文件需要保护

问题不一定必须在交割前消失，但应该进入交易文件。

例如：

历史出资存在瑕疵；

潜在税务风险；

部分知识产权尚未完成转让。

### 需要进一步核验

目前材料仍然不足。

### 持续关注

问题暂时不影响交易，但后续需要管理。

这样比单纯分：

高风险；

中风险；

低风险

更容易直接用于项目决策。

## 四、风险等级不要只让AI凭感觉打分

当然也可以增加：

高；

中；

低

这种风险等级。

但最好同时告诉Agent：

**为什么。**

比如：

高风险——可能直接影响目标公司股权、核心资产、持续经营或者交易能否完成；

中风险——可能产生一定损失或责任，但通常可以通过整改或交易条款控制；

低风险——主要属于程序、文件或者一般性合规问题。

## 五、每个问题都要告诉客户“影响是什么”

比如只写：

“部分员工未签署劳动合同。”

还不够。

应该进一步说明：

可能存在什么法律责任，以及是否会影响交易判断。

问题本身只是事实。

**影响才是客户真正关心的部分。**

## 六、最好继续给出“怎么处理”

重大问题清单如果只有风险，没有处理建议，价值还是有限。

可以继续增加：

建议补材料；

要求交易前整改；

列入交割先决条件；

要求出具承诺；

增加陈述与保证；

增加特别赔偿；

调整交易价格；

持续关注。

这样重大问题清单就开始从：

**法律报告**

变成：

**交易执行清单。**

## 七、问题一定要能够回到原报告

比如清单写：

“存在重大知识产权权属风险。”

后面律师应该能知道：

这个问题来自报告哪一章。

所以建议保留一列：

**报告位置。**

## 八、不要为了“显得专业”把所有事情都列成重大问题

如果报告里有30个一般性问题，Agent可能全部列进：

“重大法律风险”。

那这份清单就失去了意义。

所以可以直接告诉它：

**只保留真正可能影响交易判断、交易条件、交易价格、交割安排或需要客户重点决策的问题。**

重大问题清单越短，往往越有价值。

## 九、最好控制在“一眼能看完”

如果最终有：

40个重大问题；

每个写500字。

那其实又变成了一份报告。

更实用的形式是一个Excel或者几页Word。

比如表格列明：

序号；

重大问题；

主要事实；

可能影响；

建议处理；

报告位置。

## 十、最好再由律师删一轮

Agent提炼以后，我不建议原样发给客户。

律师最好再做一次：

删除；

合并；

调整风险等级；

修改处理建议。

因为所谓：

**“重大”**

本身就不是单纯的法律判断。

还可能取决于：

交易规模；

买方风险偏好；

交易价格；

行业特点；

谈判地位；

项目进度。

## 十一、这一步也可以继续用第二个Agent复核

如果前面的报告由一个Agent完成，重大问题清单也可以交给另一个Agent再看一次。

比如让它专门回答：

**“这份报告里有没有可能影响交易、但重大问题清单没有提到的事项？”**

这样可以再做一次遗漏检查。

## 直接复制的实战提示词

请根据【当前尽调报告路径】提炼一份重大问题清单，不要平均总结各章节，只筛选可能影响交易判断、交易价格、交易条件、交割安排或需要客户重点决策的事项。请逐项列明“重大问题、主要事实、风险/影响、建议处理方式、对应报告章节”，并可按照【交易前解决、交易文件保护、进一步核验、持续关注】分类。一般性、已解决或对交易影响较小的问题不要机械列入。最终生成【重大问题清单.xlsx/Word】，并标记你认为需要律师进一步判断是否属于重大问题的事项。

## 最后记住一句话

100页尽调报告解决的是：

**“我们查到了什么。”**

重大问题清单解决的是：

**“这里面什么事情真的值得客户做决定。”**

报告写完以后，再让Agent完成这一步，尽调成果才真正开始从一份法律文件，变成项目决策工具。
