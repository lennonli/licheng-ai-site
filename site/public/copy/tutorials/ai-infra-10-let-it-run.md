# AI基建的第十步：别再继续搭了，让它自己跑起来

基建搭好了，下一步不是再装新东西，是**开始自动化**——重复工作让系统自己跑：

- 每天检查有没有新的 IPO 问询和回复；
- 每周更新知识库；
- 自动同步 GitHub、备份 VPS；
- 自动整理新下载的资料；
- 定期生成新增法规、案例和监管动态摘要。

共同点：**重复、规则明确，人工做没什么价值。**

律师的自动化不是让 AI “自动出法律意见”——复杂法律判断、诉讼策略、正式文件定稿，还得律师把关。该自动化的是机械活：**查、抓、存、分、整理、同步、备份。**

比如我的 IPO 审核问询知识库，不该每周想起来手动更新一次，而是系统自己查新增项目，自动下载、整理、生成索引，最后告诉我：

> 本周新增多少项目，主要涉及哪些法律问题。

GitHub Actions、VPS 定时任务、Agent 的计划任务，都能干这些事。

别一上来就搭复杂系统。**先把一个小任务跑稳，再加下一个。** 先自动备份，再自动同步，再自动抓资料，最后串起来。否则天天修 Bug，本末倒置。

**别为了搭基建而搭基建。** 模型、Mac、MCP、GitHub、VPS 都只是工具，目标只有一个：**让越来越多重复工作不用你亲自启动。**

**成熟的AI基建，不看你装了多少工具，看有多少工作已经不用你操心。**
