# AI入门23｜Skill是什么？它和Prompt、Agent有什么区别？

前面已经讲过 Prompt，也讲过 Agent。

接下来再讲一个现在越来越常见的词：

**Skill。**

中文一般可以理解成“技能”。

对普通用户来说，先记住一句话：

**Prompt 是这一次让 AI 做什么，Skill 是一类事情通常应该怎么做，Agent 是真正负责执行任务的主体。**

## 一、为什么会出现 Skill？

假设你经常让 AI 审合同。

第一次，你需要告诉它：代表哪一方、重点看什么、怎么修改、最后输出什么。

第二次处理另一份合同，很多要求又要再说一遍。

如果这套方法本身已经比较稳定，就没有必要每次从零说明。

于是可以把这套方法保存下来，形成一个可以重复调用的 **Skill**。

所以 Skill 的核心不是“多一个按钮”，而是：

**把可重复的方法交给 Agent。**

## 二、Skill 和 Prompt 有什么区别？

Prompt 更接近当前任务说明。

比如：

> 请审阅附件中的软件采购合同，站在乙方立场，重点关注知识产权和违约责任。

这是一次具体任务。

Skill 则更接近一套通用做法，例如“合同审查 Skill”可能包含：

识别合同双方；

确认我方立场；

检查固定风险项；

必要时调用外部资料；

按照固定格式输出风险和修改建议。

所以可以简单理解：

**Prompt 是任务。**

**Skill 是方法。**

## 三、Skill 也不只是“一段很长的提示词”

有些 Skill 的确主要由文字指令组成。

但在更完整的 Agent 系统里，Skill 还可能告诉 Agent：

需要读取哪些资料；

按照什么顺序处理；

什么时候使用工具；

结果用什么格式输出；

完成后检查哪些事项。

因此 Skill 更像一个轻量化的 SOP，而不是单纯收藏了一段“万能 Prompt”。

## 四、Skill 和 Agent 也不是一回事

这一点很重要。

**Agent 是执行任务的智能体。**

**Skill 是 Agent 可以使用的一种能力或工作方法。**

同一个 Agent 可以拥有很多 Skill。

比如一个法律 Agent 里可以同时有：

合同审查 Skill；

案例检索 Skill；

尽调资料整理 Skill；

法律文件校对 Skill。

收到不同任务时，再选择不同 Skill。

所以不要把“增加一个 Skill”理解成“又增加了一个 Agent”。

## 五、Skill 和工具也不同

工具解决的是：

**Agent 能做什么动作。**

比如搜索网页、读取文件、运行代码、查询数据库。

Skill解决的是：

**这些动作应该怎样组合起来完成某一类工作。**

举个例子：

法律数据库是工具。

“法律检索 Skill”则可能规定：先识别问题，再确定关键词，再搜索法规和案例，最后核验来源并形成结论。

一个是能力，一个是方法。

## 六、为什么 Skill 对 Agent 很重要？

因为真正的工作不是每次都完全不同。

很多职业工作都有大量重复方法：

怎么审一份合同；

怎么整理一场会议；

怎么检查一段代码；

怎么制作一份周报。

如果每次都重新教 AI，Agent 就一直停留在“临时助手”阶段。

Skill 的意义，是让这些方法可以被反复调用。

## 七、不同产品里的 Skill 可能不是同一个东西

这一点也需要提醒。

Skill 目前不像 PDF、API 这类概念一样有完全统一的产品定义。

有的产品把一组指令叫 Skill；

有的 Skill 可以包含脚本和工具；

有的则更接近可安装的工作流程。

所以看到某个产品支持 Skill 时，不要只看名字。

更应该看：

**它到底保存了什么，以及 Agent 能不能在任务中真正调用它。**

## 八、这一篇只需要记住三句话

**Prompt：这一次做什么。**

**Skill：这一类事情通常怎么做。**

**Agent：调用模型、工具和 Skill 去真正完成任务。**

理解 Skill 以后，就能更容易看懂为什么成熟的 Agent 不只是“会聊天”，而是会逐渐拥有一套可复用的工作能力。
