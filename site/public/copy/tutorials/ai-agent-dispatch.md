# AI智能体智能调度工作教程

## 一、一句话原理

AI智能体不只自己干活，还能调度其他智能体（包括更强的高级分析模型）替你干活。你不需要懂任何技术——扫描文件、比对版本、修改文档、验证结果，全部由 AI 自动完成。你只需要做两件事：把需求说清楚（下提示词），以及对 AI 交回的结论把关。

## 二、四类常用场景与提示词模板

以下模板可直接复制使用，【】内容按实际替换，代码块内即为提示词原文。

### （一）场景一：审查别人的修订

用于：收到对方律师或券商修改过的文件，想知道对方改了什么、每处改动该不该接受。

提示词模板：

```text
【附件：对方修改后的文件或文件夹】
这个是【项目名】的【文件类型】，看看对方是怎么修订的，
逐处分析修改意图、是否需要接受，用高级智能模型来做这个事情。
```

说明：末句"用高级智能模型"是关键指令，AI智能体会自动调用最强分析模型出具逐项意见（建议接受／不接受／接受但补正，附理由），并留档完整意见书。不加这句则用常规模型，简单场景够用。

### （二）场景二：做成清洁版定稿

用于：修订处理完毕，要接受全部修订、清干净痕迹，发券商、交易所或客户。

提示词模板：

```text
根据现状，把【文件夹路径】的文件接受修订、删除批注
（如有标黄内容的也去除），我要发给【收件方】复核，
文件名把版本号和"修订版"字眼去掉，日期更新到最新。
```

说明：AI 会自动完成接受修订、删批注、去高亮、重命名、备份原件、逐份验证，并报告处理结果。若文件此前被人改动过（如擅自删除条款），AI 会主动披露并给出处理建议。

### （三）场景三：指定某个模型或工具干活

用于：希望指定用某个模型（高级分析模型或快速模型）执行任务。

提示词模板：

```text
把【文件夹路径】里的【文件类型】做成清洁版，调用claude sonnet模型来做。
```

或者：

```text
……用claude code中的高级智能模型来做这个事情。
```

说明：不指定时 AI智能体自行选择合适方式，指定后按指令执行。一般规律——要"判断、分析、出意见"的用高级模型，要"批量处理、格式清理"的用快速模型。

### （四）场景四：检查调度链路是否可用

用于：开工前确认外部智能体在线（首次使用或久未使用时建议先测）。

提示词模板：

```text
看一下能正常接入claude code cli吗？
```

说明：AI 会自动测试并报告；如遇登录过期、余额不足等问题，直接说"帮我修复"，AI 会带着你完成重新登录等操作。

## 三、提示词写作五要素

好的提示词能让 AI 少走弯路。按五要素组织，基本一句到位：

| 要素 | 作用 | 示例 |
| --- | --- | --- |
| 背景 | 让 AI 站对立场、用对语境 | 这是某挂牌项目挂牌后适用的章程和制度 |
| 位置 | 告诉 AI 材料在哪、处理哪个 | 把这个文件夹里的章程和制度…… |
| 要求 | 明确做什么、标准是什么 | 接受修订、删除批注、标黄的也去除 |
| 去向 | 说明用途，AI 会适配格式与命名 | 我要发给券商复核 |
| 特别指令 | 指定模型、指定输出形式 | 用高级智能模型来做 |

两个实用技巧：一是像安排助理一样说人话即可，不必写技术词汇；二是有顾虑就直接写进提示词（如"先别改，列出来给我看"），AI 会照办。

## 四、拿到结果后怎么看

AI 交回的报告通常含四块内容：处理结果（做了什么）、复核数据（验证指标）、风险披露（发现的异常与文件改动）、备份位置。律师重点看两处：

1. **结论与风险披露**：AI 发现的实质问题（如文件被人删过条款、修订有立场性改动）会单独提示，需要你决定如何处理；
2. **留档清单**：如"标黄内容清单""修订明细"等中间成果会注明存放路径，供后续逐条跟进。

法律结论永远由主办律师作出——AI 及其调度的模型只提供分析和执行，接受与否、如何答复对方，由律师判断。

## 五、遇到问题怎么办

不需要记任何排查手册，把现象原样告诉 AI 即可：

```text
调用失败了，显示403余额不足，帮我看看是什么问题。
```

```text
claude好像掉登录了，帮我修复。
```

AI 会自行诊断登录状态、账户余额、配置文件，并带着你完成修复。
