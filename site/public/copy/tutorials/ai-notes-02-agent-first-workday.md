# AI札记02｜早上打开电脑第一件事，不再是打开Office，而是打开AI智能体

我发现自己的工作习惯正在发生一个很明显的变化。

以前早上打开电脑，第一件事通常是打开：

Word、Excel、Outlook、浏览器。

看邮件，找文件，打开昨天没写完的文档，然后继续往下做。

现在越来越不是这样了。

我打开电脑以后，第一件事往往是：

**先打开AI智能体。**

这不是因为Office没用了。

而是因为工作的“入口”正在发生变化。

## 以前，我们先打开工具，再决定怎么做

传统的电脑工作方式，本质上是：

先打开一个软件，然后自己操作。

要写东西，就打开Word；

要整理数据，就打开Excel；

要查资料，就打开浏览器；

要处理邮件，就打开邮箱。

软件是工作的入口。

人自己负责：

想任务、找资料、拆步骤、操作软件、整理结果。

所以每天早上打开电脑以后，第一件事往往是先进入某一个应用。

## 现在，我更习惯先告诉Agent：今天要做什么

现在的工作方式开始变成：

先打开Agent。

告诉它：

昨天这个项目做到哪里了；

今天准备先处理什么；

哪些材料刚刚补回来；

哪一章需要继续写；

哪个问题需要查案例；

哪个文件需要重新核对。

然后再由Agent去处理具体工作。

可能最后仍然会生成：

Word；

Excel；

PDF；

Markdown。

但这些软件逐渐从：

**工作的入口**

变成了：

**工作的输出载体。**

这两个角色是不一样的。

## Word还是Word，但我已经很少从空白页开始

以前写一份文件，第一步是：

打开Word，新建一个空白文档。

然后盯着空白页开始想：

第一段写什么；

结构怎么排；

哪些资料要找；

哪些法条要查。

现在更常见的是：

我先和Agent讨论这项任务。

先让它读材料；

先把问题拆清楚；

先查法规和案例；

先搭结构；

再形成第一版。

最后我打开Word，看到的往往已经不是一个空白页。

而是一份：

**可以直接进入修改、复核和定稿阶段的文件。**

这其实是一个很大的变化。

## Excel也是一样

以前面对几十份文件，可能先打开Excel。

建表头；

一列一列设计字段；

然后自己从材料里复制。

现在我更可能先告诉Agent：

这些资料在哪里；

我要统计什么；

每一列应该是什么；

哪些数据不能猜；

最终生成一个Excel给我。

Excel当然还是非常重要。

但我不一定需要从“新建工作簿”开始工作。

Agent先完成大量整理，

我再进入Excel检查：

公式对不对；

数据有没有异常；

表格是否适合最终使用。

## 浏览器也开始变成后台工具

以前做研究：

打开浏览器；

搜索关键词；

点十几个网页；

复制内容；

再自己整理。

现在越来越多时候，我直接把研究任务交给Agent。

让它：

搜索；

打开原始来源；

查数据库；

对比不同材料；

保留出处；

最后形成研究结果。

浏览器仍然存在。

只是很多时候，它不再是我亲自操作的第一界面。

## 所以我越来越觉得：Agent正在变成新的“工作首页”

电脑以前的工作首页可能是：

桌面；

Office；

浏览器；

邮件。

未来越来越可能是：

**AI Agent。**

因为真正决定你今天怎么工作的，不再是：

“我准备打开哪个软件？”

而是：

**“我今天要完成什么任务？”**

任务先被表达出来。

Agent再去调用：

文件；

网页；

数据库；

Word；

Excel；

各种工具。

这和过去的软件逻辑其实完全不同。

以前是：

**软件 → 操作 → 结果。**

现在越来越像：

**目标 → Agent → 工具 → 结果。**

## 这并不意味着以后不需要Office

我反而觉得Office仍然会长期存在。

正式文书还是要看Word；

复杂数据还是要看Excel；

演示还是需要PPT。

但它们的角色可能会发生变化。

以前我们把大量时间花在：

“操作Office”。

以后更多时间可能花在：

**告诉Agent要完成什么，然后检查Office里的最终成果。**

也就是说：

Office从“生产界面”，逐渐变成“成果界面”。

## 这种变化最明显的地方，是每天工作的第一步

一个人的工作习惯其实很能说明问题。

以前：

早上打开电脑，先打开Word。

后来：

先打开邮箱和浏览器。

现在：

我越来越习惯先打开Agent。

看看昨天的项目做到哪里；

继续一个长期任务；

交代今天要完成的工作；

让它先跑起来。

然后我再去处理真正需要自己判断的事情。

这可能就是所谓“AI优先”最日常的一种表现。

不是每件事情都必须交给AI。

也不是Office不重要了。

而是面对一个新任务的时候，我的第一反应开始变成：

**这件事能不能先让Agent来处理？**

而不是：

**我应该打开哪个软件？**

## 最后一句

我觉得未来判断一个人是否真正进入AI工作方式，一个很简单的观察就是：

**早上打开电脑以后，他第一个打开的是什么？**

如果工作的第一入口已经从Word、Excel、浏览器，慢慢变成了AI智能体，

那改变的可能就不只是一个工具。

而是整个工作的起点。
