# AI基建的第二步：为大模型配一个好用的智能体

大模型是大脑。想让 AI 真正干活，还得给它配上手脚，也就是智能体（Agent）。

我的建议很简单：

**不知道选哪个，就选用的人多、生态成熟、长期有人维护的。**

对大多数普通用户，这比天天看跑分、比功能管用。

## 一、大模型负责想，智能体负责干

ChatGPT、Claude、Gemini、GPT、GLM、Kimi 这些，核心能力来自背后的大模型。

Codex、Claude Code、Zcode、WorkBuddy、OpenCode 这些，是智能体工作环境：能调模型、读文件、执行命令、调用工具，持续把任务做完。

在聊天框里问一句“帮我审一下这个合同”，是咨询 AI。

把整个文件夹交给智能体：“读取这个项目全部材料，结合交易背景审查合同，修改后生成 Word 文件并保存到指定目录。”这才开始接近：

**把工作交给 AI。**

## 二、用户量就是筛选机制

新工具往往功能多、界面漂亮、号称支持几十个模型，甚至宣称比主流产品强很多。看着都好。

真要拿来干活，我反而越来越保守。先看一条：

**有多少人在长期使用。**

智能体好不好用，不看官网列了多少功能，看干活时的细节：文件读取稳不稳，几十个文件漏不漏，任务会不会中途中断，上下文长了乱不乱，MCP 调不调得通，权限合不合理，模型升级后还能不能用，出错能不能恢复，历史任务留不留得住，社区里有没有人踩过同样的坑。

这些，宣传页上看不出来。大量真实用户已经替你测过一遍。

用户多，最大的好处不是流行，是生态。

遇到报错，冷门工具搜半天可能只有作者自己的文档；主流工具，GitHub、Reddit、X、知乎、小红书甚至微信群里早有人遇到过，复制报错信息很快就能找到解法。

MCP 服务优先适配的，通常也是用户最多的平台。教程、Skill、插件、配置文件、工作流，都先围绕它们长出来。

正循环就这么形成了：

**用户越多 → 教程越多 → 插件越多 → Bug越容易暴露 → 修复越快 → 更多人使用。**

## 三、法律工作要稳定，不要新奇

律师用 Agent 不是玩 Demo。交出去的可能是整个 IPO 项目文件夹：招股说明书、律师工作报告、法律意见书、反馈回复、尽调底稿、工商资料、合同、会议纪要、Excel 清单。

偶尔聊天，工具出点问题无所谓。让智能体连续跑一个小时、分析几百个文件，最后突然崩掉，代价就大了。

所以专业工作里，我看重的是**稳定性、持续维护、用户规模和生态**，不是功能数量。

小众 Agent 某个功能再惊艳，要把长期工作系统建在它上面，我也会非常谨慎。

AI 基建看的不是今天能不能跑起来，而是：

**半年以后还能不能继续用。**

## 四、不要频繁换智能体

这是 AI 重度用户最容易掉的坑。

今天看到新 Agent，装；明天又一个，迁；过几天出个排行榜，再换。最后电脑里十几个 AI 工具，没一个形成稳定的工作习惯。

智能体不像普通软件，用得越久越值钱。

你会慢慢攒下自己的全局指令、提示词、Skill、MCP、项目目录、知识库和操作习惯。到最后，不只是“会用一个 Agent”，而是：

**这个 Agent 已经长成了你的工作环境。**

换一次，迁移成本就高一截。

所以主力智能体别多。选一个真正成熟的，长期用；再备一两个备用的，够了。

## 五、我会怎么选

我不会先研究几十个 Agent、做一张巨大的功能评分表。只看几件基本的事：

用户够不够多；开发者是否持续更新；背后的公司或开源社区是否可靠；能不能用第一梯队的大模型；能不能读取和修改本地文件；能不能调用 MCP；能不能跑较长的复杂任务；出了问题，网上能不能找到大量解决方案。

这些过关了，再看界面、价格和具体功能。

所以 Codex、Claude Code 这类主流智能体，以及国内用户较多的 Zcode、WorkBuddy 等，我都会优先研究。

不是人多的一定最好。而是对生产工具来说：

**大量真实用户长期愿意留下来，本身就是很有价值的评价指标。**

## 六、模型可以换，智能体尽量稳定

大模型我会一直追谁更强，因为模型能力直接决定工作质量。

智能体我不愿常换，因为它承载的是我整套工作方式。

**模型可以不断换，智能体尽量稳定。**

今天 GPT 强，就让 Agent 调 GPT；明天 Claude 更适合法律写作，就切 Claude；以后国产模型更强，接 GLM、Kimi 或别的模型。承载这些模型的工作环境，没必要天天换。

第一步，找一个足够强的大脑。第二步：

**给这个大脑装上一副成熟、稳定、用户足够多的手脚。**

别一上来就追最冷门、最新奇、参数最多的工具。好用比新重要，稳定比功能多重要，生态比孤立的亮点重要。

判断这些，最简单的办法之一，就是看：

**到底有多少人愿意每天拿它来真正干活。**
