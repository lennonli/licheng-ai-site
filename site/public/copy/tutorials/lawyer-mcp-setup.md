# 律师 MCP 搭建实用教程

一句话总结：把法律常用的五个数据库装进 AI 客户端，装的过程全部交给 AI——您只需要拿到密钥、粘贴提示词、审查结果。

## 一、本对话用到的 MCP、客户端与 Skill

### （一）五家数据库 MCP

| 名称 | 能干什么 | 计费 | 接入形态 |
| --- | --- | --- | --- |
| 北大法宝 | 法条法规检索与效力核验、案例检索、引证校验、案号识别 | 账号套餐 | ZCode 走本地桥 ~/.pkulaw-bridge，其余客户端同桥或直连 |
| 元典 | 法规、案例语义检索、企业信息、证券合规，共 4 个端点 | 点数计费 | http 直连（ZCode/Codex）、聚合桥（Claude）；已配双 Key |
| 企查查 | 工商、风险、知产、沿革、董监高、招投标等 10 个端点、169 个工具 | 积分制，agent.qcc.com 充值 | 同上 |
| 见微数据 | A 股与新三板公告 812 万+条、IPO／再融资／重组审核进程 | 按次计费 | 本地程序（stdio），四端一致；已配双 Key |
| 腾讯 ima | 个人与共享知识库、笔记的检索和写入 | 随账号 | 官方无 MCP，走 Skills＋OpenAPI |

### （二）四个 AI 客户端

- **ZCode（主力）**：配置在 ~/.zcode/cli/config.json，远程与本地服务器都支持，还能按领域建检索子代理；
- **Codex CLI**：配置在 ~/.codex/config.toml（TOML 格式），Token 直接写在文件里；
- **Claude 桌面版**：配置在 ~/Library/Application Support/Claude/claude_desktop_config.json，只支持本地型（stdio）服务器，远程数据库须经本地桥中转；
- **Claude Code CLI**：技能读 ~/.claude/ 目录，MCP 用 claude mcp add 命令。

### （三）两个 Skill

- **ima-skill**（腾讯官方包）：让 AI 直接搜您的 ima 知识库、上传文件、收藏网页、读写笔记；
- **见微 Skill**：公告检索的 MCP 配套说明，教 AI 用好三层关键词与省费检索。

### （四）两个自建组件

- **本地聚合桥**（~/.mcp-aggregator、~/.pkulaw-bridge）：一个本地小程序把多家远程端点合并成一个服务器——Claude 桌面版必需，顺带实现"额度用尽自动切备用 Key"；
- **检索子代理**（~/.zcode/agents/）：法规、判例、上市公司公告、企业工商四个检索专员加一个官方来源核验专员，主对话自动调用，检索纪律已写死在代理提示词里。

## 二、怎么装：直接发给 AI 的提示词

把【】替换成实际内容，发给能操作本机文件的 AI 助手（ZCode、Claude Code、Codex 均可）。

### （一）新装一家数据库（最常用，把服务商配置贴进去）

```text
【把服务商给的 MCP 配置原样粘贴在这里】
请安装到本机：
1.先 curl 探活每个端点，全部 200 再写入；
2.只合并新增条目，不覆盖原有配置，改前备份；
3.装完做一次最小真实调用验证（注意计费，选免费接口）；
4.结果写入你的长期记忆，并用编号清单汇报。
```

### （二）装到另一个 AI 客户端

```text
把本机现有全部 MCP 服务器同步安装到【Codex／Claude 桌面版】：
先确认目标客户端格式（Claude 桌面版仅支持本地型，远程的
自建聚合桥中转）；只合并不覆盖、先备份；装完验证并汇报差异。
```

### （三）双 Key 轮换（额度接力）

```text
为【服务名】配双 Key 轮换，第二把 Key：【粘贴】
先真实调用一次确认新 Key 可用（会员/点数一并确认）；
把"固定主用主 Key，配额/余额/会员类报错才用备用 Key 同参数
重试一次"写入你的长期记忆；Claude 桌面版在桥内自动切换。
```

### （四）接入腾讯 ima 知识库

```text
帮我接入腾讯 ima 知识库：先查官方最新接入方式（官方无 MCP
就走 Skills＋OpenAPI，拒绝需抓 Cookie 的逆向方案）；下载官方
技能包装入技能目录；凭证存 ~/.config/ima 并收紧 600 权限；
最后只读实测一次（列出我的知识库）确认链路。
```

### （五）连不上排障

```text
【服务器名】连不上，其他正常。请排查：
1.curl 对比正常与故障端点（POST 握手与 GET 各测一次）；
2.核查配置字段（多余字段会被静默丢弃）；
3.定位后修复（网关拒 GET 的直接改本地桥绕开），
端到端实测后汇报。
```

### （六）建检索子代理（ZCode）

```text
按领域建检索子代理：法规、判例、上市公司公告、企业工商
各一个，另加官方来源核验一个；把检索纪律写进代理提示词：
法条逐字取原文核效力、案号回库核验、穿透比例逐字引用
禁止自行乘算、按次计费库优先宽条件一次查足。
```

## 三、注意事项

1. **Token 等于账号额度**：凭证文件权限收紧为 600，不入同步盘、下载目录和版本库，不发给云端托管 AI；怀疑泄露立即撤销重发。
2. **装前探活、装后实测**：握手成功不等于数据可用——计费和额度在调用层才拦截（实测出现过"全部握手正常、一调用就提示积分不足"）。
3. **配置只合并不覆盖**：客户端配置文件里还有别的设置，整文件覆盖会出事故；改动后新开会话（Claude 桌面版须彻底退出重开）才生效。
4. **省着用**：见微按次计费——用预设范围（招股书/年报/问询回复）、宽条件一次拿足；元典常查余额（get_user_balance）；企查查积分在 agent.qcc.com 充值。
5. **双 Key 须两个独立账号**：同账号多 Key 额度共享则无意义；多账号使用先向服务商确认条款。
6. **数据库结果不直接进正式文书**：正式援引法条、案例前仍须到官方来源（人大法规库、政府网、两高）逐字核验，案号回库验证——这是反编造红线。
7. **客户资料保密**：把客户文件上传进任何知识库或解析服务前，先过保密义务评估。
8. **每月一次安全盘点**：让 AI 盘点全部 Token 位置与权限，只出风险清单不动文件。
