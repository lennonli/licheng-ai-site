# 网核网站

<p class="section-lead">以下网站用于企业登记、公共信用、知识产权、域名、行政监管、司法执行及综合风险信息等公开网络核查。清单根据核查目的分类整理。</p>

<div class="tool-note">网站页面、验证码和访问策略可能随时调整。遇到验证码、滑块或安全防护时，应使用正常浏览器人工完成，不要频繁重复自动访问；查询结果仍需结合主体名称、统一社会信用代码和页面证据核验。</div>
