建议每 1—3 个月检查一次：域名是否跳转、产品是否更名、开源仓库是否归档、MCP Server 是否变更权限或收费模式；同时继续删除失活、重复或明显边缘化的条目。对准备安装到本地电脑或律所网络的 Agent/MCP，应先在隔离环境测试，并使用最小权限的独立 API Key。
