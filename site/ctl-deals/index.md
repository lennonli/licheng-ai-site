## 核心字段说明

每单案例的主要字段如下（完整字典见数据仓 README）：

| 字段 | 说明 |
| ---- | ---- |
| code / name / board | 证券代码 / 公司简称 / 上市板块 |
| status / status_date | 交易状态（过户完成 / 进行中 / 已终止）与状态日期 |
| first_announce_date / sign_date | 首次公告日期 / 协议签署日期 |
| transferors / transferees | 转让方 / 受让方（数组，含交易前后持股比例等） |
| change_type | 变更方式：直接协议转让 / 间接收购 / 表决权委托 / 一致行动协议 / 司法拍卖等 |
| structure | 交易结构标签数组（如 ["协议转让", "一致行动"]） |
| shares / pct | 转让股数 / 占总股本比例 |
| price_per_share / total_amount / premium_pct | 转让单价 / 交易总价 / 溢价率（按公告原文记录） |
| payment | **付款节奏**：分期安排、共管账户、与过户的挂钩条件 |
| conditions | **先决条件**：协议生效与交割的前提（数组） |
| breach | **违约责任**：违约金标准、解除权、赔偿范围 |
| reps_warranties | **陈述与保证** |
| transition | **过渡期安排**：签约至交割期间的权利义务 |
| tax | **税费承担** |
| evidence | 引证：每个关键字段对应公告原文的文件名与引文（引文不超过 60 字，可回原文核对） |
| completeness / notes | 协议披露完整性（协议全文已披露 / 仅摘要条款 / 未披露协议条款）/ 备注（含资料异常说明） |

**null 约定**：字段值为 null 表示已核查公告原文但未披露，**不是**数据缺失；引用时不要把 null 解读为「无此条款」。

六大条款是这个数据库的核心价值：全库 1,228 单中，协议全文已披露 205 单、仅摘要条款 499 单、未披露协议条款 507 单（另有 17 单未标注）——披露越完整，条款原文越可直接用于起草与审查比对。

### 合金投资（000633，深主板）——直接协议转让

- 转让方：霍尔果斯通海股权投资有限公司 → 受让方：广汇能源股份有限公司（实际控制人孙广信）
- 转让 77,021,275 股，占总股本 20.00%；单价约 9.7439 元/股，总价款 750,487,601 元
- 2022 年 6 月 15 日签约，2022 年 7 月 8 日过户完成；先决条件 7 项
- 付款节奏摘录：「分期支付并设共管账户：协议签署后 2 个工作日内双方在中国银行设立共管账户；共管账户设立完成当日或下一工作日乙方向共管账户支付 400,000,000 元；深交所审核通过出具确认意见书后 3 个工作日内释放 400,000,000 元至甲方指定账户并办理过户交割……」
- 违约责任摘录：「逾期付款或逾期转让按每逾期一日万分之五的标准支付违约金，逾期超过 20 个工作日对方有权单方解除；甲方发生第 8.2 条第（2）项重大违约情形，乙方有权解除协议且甲方应支付相当于股份转让总价款 10% 的违约金……」

### 聆达股份（300125，创业板）——间接收购（转让控股股东合伙份额）

- 转让方：王正育、王妙琪 → 受让方：金寨华成未来新能源科技合伙企业（有限合伙）、海波里斯绿能科技（重庆）有限公司
- 转让标的不是上市公司股份本身，而是控股股东杭州光恒昱的 100% 合伙财产份额，间接控制上市公司 58,453,260 股，占总股本 22.02%；总价款人民币 110,000 万元（11 亿元）
- 2022 年 8 月 8 日签约，2022 年 8 月 17 日过户完成

- 违约责任摘录：「甲方收首期款后三个工作日未完成过户，应立即退还30,000万元并支付10,000万元惩罚性违约金，乙方有权解除合同。非因乙方过错甲方拖延过户，每日按第一期价款万分之五付违约金，上限20%……」

### 科德教育（300192，创业板）——直接协议转让＋一致行动

- 转让方：吴贤良 → 受让方：深圳华芯未来投资合伙企业（有限合伙）、中国东方国际资产管理有限公司
- 转让 77,584,267 股，占总股本 23.5716%（华芯未来 18.5716%、东方国际资管 5.0000%）；单价 17.21 元/股，总价款 1,335,225,235.07 元

## 数据来源与质控

- 来源：交易所与巨潮资讯披露的上市公司公告原文（提示性公告、股份转让协议、权益变动报告书、过户公告等）。
- 抽取与校验：AI 多模型抽取后经全量质控校验（JSON 合法性、必填字段、引文回原文比对），2022–2026 各年度均已通过同口径校验。
- 已知异常：约 15 单存在源文件错配（目录名与正文证券代码不符），已在各单 notes 中如实标注、相关字段填 null，未做推测填充；另有少数案例仅为控股股东更名、不构成实质控制权变更，同样在 notes 中注明。

## 使用方式

- **网页检索**：上方检索入口，适合按公司、代码、变更方式快速定位案例。
- **程序调用**：数据仓为公开仓库，可直接读取各年度 `index.json` 与单案 JSON；配套的开源 MCP 服务（[lennonli/ctl-deals-mcp](https://github.com/lennonli/ctl-deals-mcp)）提供 search_deals、get_deal、search_clauses、stats 等工具，可按条款类型检索六大条款原文，供 AI 智能体在起草、审查股份转让协议时调用。

数据来源于上市公司公开披露，仅供研究学习，不构成法律意见；对外法律判断与文件须经人类律师复核。
